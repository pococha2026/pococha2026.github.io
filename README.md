# Pococha1012 公開ツール集

公開一覧：https://pococha2026.github.io/

一覧は6つのツールへのリンクだけです。各ツール本体は、個別に公開／所有者限定を切り替えられる配信先に置いています。このリポジトリの現在のHTMLは案内・データ移行用です。

公開停止は配信先のアクセス設定で行います。リンクを消す、JavaScriptで画面を隠す、共通パスワードをHTMLへ埋め込む方法はアクセス制限に使いません。GitHub Pagesへツール本体やオフラインZIPを再配置しないでください。

旧ページは保存済みデータがなければ新しいURLへ移動します。保存データがある場合はバックアップ画面を表示し、localStorageを削除しません。コメント・プロフィール・記録の新配信先では移行バックアップを読み込めます。メーターは専用JSONも出力できます。コインは入力JSONを出力できます。解答の表示設定などの移行バックアップは保管用です。

すでに保存・ダウンロードされたHTMLやオフライン版、公開されていたGit履歴のコピーは、あとから失効させることはできません。非公開切り替えは現行の配信先へのアクセスを制限します。
