選択するとすぐに反映されます。設定はこの端末・ブラウザーに保存されます。標準テーマは端末の明るい／暗い表示に合わせます。フォントの見え方は端末によって異なります。

ブラウザーでツールを直接開く

Chromeで開く（iPhone・iPad） Safariで開く（対応端末） Chromeで開く（Android）

Safariの直接リンクは対応するiPhone・iPad・Mac向けです。OS・アプリ・既定のブラウザー設定によって、開けない場合や別のブラウザーで開く場合があります。

Safariが開かない場合は、URLをコピーしてSafariのアドレス欄に貼り付けてください。ChromeのリンクにはChromeアプリが必要です。

このツールを開く

iPhone（Safari）

Safari公式アプリ（App Store）
  1. 上の「Safariで開く（対応端末）」をタップします。開けない場合は「ツールのURLをコピー」をタップし、Safariのアドレス欄に貼り付けます。
  2. ページメニューから「共有」を選びます。共有ボタンが表示されている場合は、そのボタンをタップします。
  3. 共有メニューを下にスクロールし、「ホーム画面に追加」を選びます。見つからない場合は、最下部の「アクションを編集」から追加します。
  4. 「ウェブアプリとして開く」が表示されたらオンにし、「追加」をタップします。
Apple公式の説明

iPhone（Chrome）

Chromeを入れる（App Store）
  1. 上の「Chromeで開く（iPhone・iPad）」をタップします。Chromeが入っていない場合は、公式アプリリンクから入れてください。
  2. アドレスバー右側の共有アイコンをタップします。
  3. 共有メニューを下にスクロールし、「ホーム画面に追加」をタップします。
  4. 表示される名前を確認し、「追加」をタップします。
Google公式の説明

Android（Chrome）

Chromeを入れる（Google Play）
  1. 上の「Chromeで開く（Android）」をタップします。切り替わらない場合は、URLをコピーしてChromeに貼り付けてください。
  2. アドレスバー右側の「⋮」をタップします。
  3. 「インストールしてショートカットを作成」から「ショートカットを作成」を選びます。
  4. 表示される名前を確認し、「追加」をタップします。
